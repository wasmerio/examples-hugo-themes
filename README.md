# Wasmer Hugo theme templates

278 Hugo themes packaged as Wasmer Edge templates. These were split out of
[`wasmerio/examples`](https://github.com/wasmerio/examples) so that repo stays small.

**Each theme belongs to its upstream author.** Every folder has an `UPSTREAM.json` that pins the
upstream repository, commit, and license. Deploy links should point at the upstream repo; the
folders here are the Wasmer build configuration plus demo content that was used to verify each theme.
